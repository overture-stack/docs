# Deploying Overture

**For teams standing up and operating an Overture instance.**

This guide walks through deploying the Overture stack yourself, step by step: authorization with Keycloak, file transfer with Song and Score, tabular data submission with Lectern and Lyric, then the search portal with Maestro, Arranger, and Stage, and optionally the MCP server for AI-assisted, conversational data discovery.

If you'd rather try things out locally first, the [**Use docs**](/use) guides each ship with their own locally deployable demo environment.

We're actively working on updating and expanding these docs with guidance on Kubernetes and Helm chart deployments and deployment best practices.
