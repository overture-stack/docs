# Arranger API

Arranger is Overture's search API. Unlike the services above it is a **GraphQL** API rather than REST/Swagger: a client sends a [SQON](/develop/Arranger/reference/building-sqon-queries) filter with field selections to a single `/graphql` endpoint, and Arranger translates it into an Elasticsearch query. It also exposes read-only **introspection** REST endpoints for discovering a server's catalogues and fields.

Arranger's API is documented in the Arranger component reference:

- [**Query processing**](/develop/Arranger/reference/query-processing): how a search request flows from SQON through GraphQL to Elasticsearch.
- [**Building SQON queries**](/develop/Arranger/reference/building-sqon-queries) and [**SQON in detail**](/develop/Arranger/reference/sqon-in-detail): the filter language.
- [**Introspection API**](/develop/Arranger/reference/introspection): read-only REST endpoints describing a server's catalogues, fields, types, and operators.
- [**Arranger MCP server**](/develop/Arranger/mcp-server): the MCP server that wraps this API for AI-agent access.
