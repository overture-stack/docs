# Publication & Citation

Overture is published in *GigaScience*, volume 14, 2025, article giaf038.

**[Publications](/impact/publications/)** on the Overture website carries the
paper, the author list, and ready-to-copy citations in standard, APA, Vancouver
and BibTeX formats.

Please cite it when you use Overture components in your research, build a data
platform with them, reference the architecture, or compare genomics data
platforms.

```
Shiell, M., Bajari, R., Andric, D., et al. Overture: an open-source genomics data platform.
GigaScience 14, giaf038 (2025). https://doi.org/10.1093/gigascience/giaf038
```
