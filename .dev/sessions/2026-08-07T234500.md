## The redirects

`website/netlify/marketing-redirects.toml`, with a README beside it. Sixteen rules: the twelve `/documentation/*` ones lifted verbatim, plus the four routes the rebuild retired. Verified programmatically before deleting the source that every one of the twelve carried over with its target, status and `force` flag unchanged, and in the same order, since Netlify matches in file order and the catch-all has to stay last.

**It is deliberately not a `netlify.toml`.** This repo has no live Netlify config: `docs.overture.bio` is configured through the Netlify UI, so committing one would move the build command, publish directory and environment out from under a working site. Netlify reads `netlify.toml` from the base directory, which here is `website/`, so a file one level down under another name is inert. Both the file header and the README say so, because the failure mode is someone renaming it to be helpful.

The four new rules carry no `force`, unlike the twelve inherited ones: those pages genuinely do not exist in the new build, and Netlify applies a redirect only when nothing else matches. Forcing would mask a future page at the same path.
